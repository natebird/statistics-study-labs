# Statistics Study Labs

Interactive study pages for **AP Statistics**, one lab for every topic in the revised (2026–27) course's five units. Each lab has data you can edit, graphs and simulations that react, a live explanation of what changed and why, show-your-work calculations, a reference table, FRQ tips, common mistakes, eight AP-style practice questions, and the key terms for that topic.

Live site: https://statistics.natebird.co

## Terminology guides

A searchable glossary of every key term in the course, with flashcards (progress saved in the browser) and a self-quiz.

- [Master guide: all five units](terms/index.html)
- Unit guides: [1](terms/unit-1.html) · [2](terms/unit-2.html) · [3](terms/unit-3.html) · [4](terms/unit-4.html) · [5](terms/unit-5.html)

Terms live in `assets/glossary/unit-N.js`. Each term is stored once, in the topic where the course introduces it, and an `also` list places it in later topics that reuse it.

## Calculator guide

[calculator.html](calculator.html) shows every procedure in the course in Desmos (the calculator built into Bluebook) and on the TI-84, side by side. The labs use the same commands through `Lab.CMD` in `assets/lab.js`.

## Using it

Open `index.html` in any browser, or visit the site. There is no build step and nothing to install. Every page is plain HTML, CSS, and JavaScript.

## Layout

```
index.html          Landing page linking every lab (generated)
assets/lab.css      Shared styles (light and dark themes)
assets/prefs.js     Appearance picker: light/dark mode and accent color
assets/lab.js       Shared helpers: topic list, statistics and distribution math (normal, t, chi-square,
                    binomial), seeded random numbers, dotplots, histograms, boxplots, bar charts, quiz, navigation
assets/glossary.js  Glossary viewer: term list, flashcards, quiz
assets/glossary/    Term data, one file per unit
labs/               One page per course topic (N-k-slug.html)
scripts/            build_index.py regenerates index.html from the topic list
terms/              Master glossary and one page per unit
```

## A note on the course

Topics follow the AP Statistics Course and Exam Description effective fall 2026, which reorganized the course from nine units into five. Data sets in the labs are made up for practice unless a lab says otherwise.

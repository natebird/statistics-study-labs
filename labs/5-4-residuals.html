2. Key ideas

Definition

Residual = y − ŷ

A residual is the actual value minus the predicted value. It is the vertical distance from a point to the regression line, with a sign.

Sign

Above or below the line

A positive residual means the point is above the line, so the model underestimated. A negative residual means the point is below the line, so the model overestimated.

Balance

Residuals add to zero

For the least-squares line, the residuals always sum to 0 (and so their mean is 0). Large positive misses are balanced by negative ones.

Residual plot

Residuals vs. x

A residual plot graphs each residual against the explanatory variable (or against ŷ). It magnifies the misses so patterns are easier to see than in the scatterplot.

Appropriateness

Look for no pattern

If the residual plot shows random scatter around 0, a linear model is appropriate. A curved pattern means the relationship is not linear. A fan means the spread changes with x.

Spread

s, the typical residual

s = √(Σ residual² ÷ (n − 2)) estimates the typical size of a prediction error, in the units of y. Smaller s means predictions are closer to the actual values.

4. On the FRQ

How to earn the points

  • Calculate a residual as actual − predicted, and show both values: "residual = 21.0 − 18.6 = 2.4."
  • Interpret a residual in context: "This car's actual price is $2,400 higher than the price predicted by the regression line."
  • Justify linearity with the residual plot: "Because the residual plot shows no apparent pattern, a linear model is appropriate."
  • Interpret s in context: "The actual prices typically differ from the predicted prices by about $1,800."
  • When a residual plot curves, say the linear model is not appropriate, even if r is close to 1.

Common mistakes

  • Computing predicted − actual. The order is actual − predicted (y − ŷ).
  • Saying a positive residual means the model overestimated. Positive means the point is above the line, so the model underestimated.
  • Using r or r² alone to decide if a linear model is appropriate. A curved relationship can still have r near 1.
  • Describing a residual plot as "linear" or "positive." Describe whether there is a pattern.
  • Forgetting the units of s and of a residual: they are in the units of y.

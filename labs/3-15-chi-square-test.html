2. Key ideas

Statistic

Distance from H₀

χ² = Σ (O − E)² / E adds up how far each observed count is from its expected count, relative to the expected count. χ² = 0 means a perfect match.

Distribution

Right-skewed, depends on df

Chi-square distributions take only nonnegative values and are skewed right. Their mean equals df, and they become more symmetric as df grows.

p-value

Always the right tail

The p-value is P(χ² ≥ observed) using df = (r − 1)(c − 1). Large χ² values give small p-values.

Follow-up

Which cells matter most?

Look at the largest components to see where the observed counts differ most from expected, and say whether each is above or below expected.

Conclusion

In context

Homogeneity: convincing evidence the distributions differ among the populations. Independence: convincing evidence of an association between the variables.

Scope

Design limits claims

A randomized experiment supports cause and effect. Random samples support generalizing to the populations. An association in observational data is not causation.

4. On the FRQ

How to earn the points

  • Show the formula and at least one component: (38 − 28.67)² ÷ 28.67 = 3.04.
  • Report χ², df, and the p-value together.
  • Compare the p-value to α and state the decision about H₀.
  • Write the conclusion in context using the language of the test (distributions differ / association).
  • When asked which cells contributed most, name the cell and say whether the observed count was above or below expected.

Common mistakes

  • Using df = n − 1 or the number of cells instead of (r − 1)(c − 1).
  • Dividing by the observed count instead of the expected count in each component.
  • Shading the left tail or doubling the p-value.
  • Concluding causation from a test for independence on observational data.
  • Saying "the data prove the variables are independent" after failing to reject H₀.

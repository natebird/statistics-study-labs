2. Key ideas

Plausible values

The interval is the evidence

Values inside a confidence interval are plausible for the parameter. Values outside are not plausible at that confidence level.

Zero

Is there a difference?

If 0 is in the interval for p₁ − p₂, no difference is plausible, so there is not convincing evidence the proportions differ. If 0 is outside, there is.

Direction

Which group is higher?

An interval entirely above 0 supports p₁ > p₂. An interval entirely below 0 supports p₁ < p₂. Check the order of subtraction before you decide.

Careful

Plausible is not proven

A value inside the interval is plausible, not established. "0 is in the interval" never proves the proportions are equal; it means we cannot rule equality out.

Width

Sample size and confidence

Larger samples give narrower intervals. Higher confidence gives wider intervals. To halve the margin of error, use about four times as many people in each group.

Scope

Cause and generalization

Random assignment lets you conclude cause and effect. Random sampling lets you generalize to the populations. A claim needs the right design, not just the right interval.

4. On the FRQ

How to earn the points

  • Refer to the interval explicitly: "Because 0 is not contained in the interval (0.03, 0.12)…"
  • Tie the decision to the parameter and context: "…there is convincing evidence that the true proportion of A is greater than that of B."
  • For a specific claimed value, say whether it is in the interval and call it plausible or not plausible.
  • If the interval includes values on both sides of a claim, say the data do not provide convincing evidence for the claim.
  • When asked about width, name the cause: a larger sample size reduces the standard error; a higher confidence level increases z*.

Common mistakes

  • Saying "the interval proves there is no difference." It only shows no difference is plausible.
  • Ignoring the order of subtraction and reversing the direction of the conclusion.
  • Claiming causation from an observational study.
  • Using the point estimate alone ("0.075 is greater than 0, so p₁ > p₂") without checking the whole interval.
  • Thinking a higher confidence level makes the interval more precise. It is less precise (wider).

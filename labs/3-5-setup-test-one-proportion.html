2. Key ideas

Null hypothesis

H₀: p = p₀

The null is the claim of no change or no difference. We assume it is true and ask whether the data are surprising under it.

Alternative

Hₐ: <, >, or ≠

The alternative is what the researcher suspects. One-sided (< or >) for a directional suspicion; two-sided (≠) for "different" or "changed."

Parameter

Always about the population

Define p in context: "the true proportion of all … who …". Never write hypotheses with p̂.

Significance level

α, chosen in advance

α is the cutoff for how unlikely the data must be under H₀ before we reject it. Common choices: 0.05, 0.01, 0.10.

Conditions

Random, 10%, Large counts

Random sample or random assignment; n ≤ 10% of the population; np₀ ≥ 10 and n(1 − p₀) ≥ 10, using the null value.

Null model

N(p₀, √(p₀(1 − p₀)/n))

If H₀ is true and conditions hold, p̂ has an approximately normal distribution centered at p₀. That's the yardstick for the test.

4. On the FRQ

How to earn the points

  • Write both hypotheses in symbols and define p in words with context.
  • Name the procedure: "one-sample z-test for a population proportion."
  • Check conditions with numbers using p₀: "150(0.10) = 15 ≥ 10 and 150(0.90) = 135 ≥ 10."
  • State α before doing calculations. If none is given, use α = 0.05 and say so.
  • Explain why the alternative is one- or two-sided using the wording of the question.

Common mistakes

  • Writing hypotheses about p̂ or using the sample value in H₀.
  • Putting the researcher's suspicion in the null and the status quo in the alternative.
  • Checking Large Counts with p̂ instead of p₀ (for a test, use the null value).
  • Choosing a one-sided alternative because the sample happened to go that direction.
  • Defining the parameter as "the proportion of students" without saying all students or what characteristic.

2. Key ideas

Test statistic

Standardized difference

z = (statistic − null value) ÷ standard error. It counts how many null standard errors the observed difference p̂₁ − p̂₂ is from 0.

p-value

Probability, assuming H₀

The p-value is the probability of getting a difference at least as extreme as the one observed, in the direction of Hₐ, if H₀ is true. For ≠, double the one-tail area.

Decision

Compare p to α

If p-value < α, reject H₀: the result is statistically significant. If p-value ≥ α, fail to reject H₀. Never "accept" H₀.

Conclusion

Context and evidence

Say whether there is convincing evidence for Hₐ, in the words of the problem. Mention the p-value and α.

Scope

Cause or generalization

With random assignment, a significant result supports causation. With random sampling, the result generalizes to the populations. Without either, be careful.

Significance vs. importance

Big n finds small effects

With very large samples, tiny differences can be statistically significant. Statistical significance is not the same as practical importance.

4. On the FRQ

How to earn the points

  • Show the test statistic with numbers: z = (0.47 − 0.39 − 0) ÷ √(0.43(0.57)(1/300 + 1/300)) = 1.98.
  • Give the p-value and how you got it (normal curve, area, direction).
  • Compare the p-value to α explicitly: "Because 0.024 < 0.05, we reject H₀."
  • Write the conclusion about the parameters in context: "There is convincing evidence that the true proportion…"
  • If asked, interpret the p-value: "Assuming there is no difference, the probability of observing a difference of 0.08 or more by chance is 0.024."

Common mistakes

  • Concluding "H₀ is true" or "we accept H₀." Say "fail to reject" and "not convincing evidence."
  • Interpreting the p-value as the probability that H₀ is true.
  • Forgetting to double the tail area for a two-sided test.
  • Using unpooled SE in the test statistic.
  • Claiming causation from random samples, or generalizing from a volunteer experiment to all people.

2. Key ideas

Data

Individuals and variables

Individuals are the people, animals, or objects described by a data set. A variable is any characteristic that can differ from one individual to the next.

Type 1

Categorical variables

Values are labels or groups, such as eye color or yes/no. Summarize them with counts and proportions. Some categorical variables use numbers as labels, like zip codes or jersey numbers.

Type 2

Quantitative variables

Values are numerical amounts, such as height or the number of siblings, where means and differences make sense.

Counts

Discrete

A discrete quantitative variable takes a countable set of separate values, usually whole numbers from counting: pets, goals, siblings.

Measures

Continuous

A continuous quantitative variable can take any value in an interval: time, weight, temperature. Rounding the recorded value does not make it discrete in the AP sense.

Why it matters

Type decides the tools

Categorical data get bar charts, pie charts, and proportions. Quantitative data get dotplots, histograms, boxplots, means, and standard deviations.

4. On the FRQ

How to earn the points

  • When asked to identify a variable, name it in context and give its type: “Minutes of exercise per week is a quantitative variable.”
  • Justify the type: “It is categorical because each response places a student into a group.”
  • Choose graphs and summaries that match the type, and say why. A bar chart for a categorical variable; a histogram or boxplot for a quantitative one.
  • Identify the individuals explicitly when asked: they are the objects in each row, not the variables.

Common mistakes

  • Calling a variable quantitative just because its values are numbers (zip codes, jersey numbers, area codes).
  • Making a histogram of a categorical variable. Use a bar chart, with gaps between the bars.
  • Calling time or weight discrete because they were rounded. Measurements are continuous.
  • Confusing the variable (“height”) with its values (“170 cm”) or with the individuals (“the students”).

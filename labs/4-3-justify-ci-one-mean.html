Justifying a Claim with a Mean Interval Study Lab

A confidence interval gives the plausible values of a parameter. If a claimed value of μ (or μd) is inside the interval, the data do not give convincing evidence against the claim. If it is outside, they do. Set up an interval, move the claim, and practice writing the justification.

2. Key ideas

Plausible values

The interval is a list of believable values

Every value inside the confidence interval is a plausible value of the parameter, based on the data. Values outside the interval are not plausible at that confidence level.

Claim inside

Not convincing evidence against it

If the claimed value is in the interval, the data do not give convincing evidence that the claim is wrong. That is not proof the claim is right: many other values are plausible too.

Claim outside

Convincing evidence against it

If the whole interval is below the claim, the data give convincing evidence that the true mean is less than the claim. If it is all above, convincing evidence that it is greater.

Mean difference

Watch for 0

For paired data the usual claim is μd = 0 (no difference on average). An interval entirely above 0 or entirely below 0 is convincing evidence of a real mean difference in that direction.

Link to tests

Two-sided test at α = 1 − C

A C% interval and a two-sided test at α = 1 − C agree: the claim is rejected by the test exactly when it falls outside the interval. A 95% interval matches a two-sided test at α = 0.05.

Width matters

More data, sharper answers

Larger samples give narrower intervals, which can rule out claims a small sample could not. Higher confidence gives wider intervals, which rule out fewer claims.

4. On the FRQ

How to earn the points

  • Refer to the interval directly: "Because 16 is not in the interval (15.69, 15.96)…" Graders look for the link between the claim and the interval.
  • Say plausible or not plausible, and then state the conclusion about the parameter in context.
  • For a claim like "at least 500 hours," notice the direction: an interval entirely below 500 contradicts it; an interval containing 500 does not.
  • If the question asks about a two-sided test, mention that a C% interval matches a test at α = 1 − C.

Common mistakes

  • Saying "the interval proves the mean is 16." A claim inside the interval is plausible, not proven.
  • Comparing the claim to x̄ instead of to the interval. x̄ will almost never equal the claim exactly.
  • Concluding about individuals: "most boxes weigh less than 16 oz." The interval is about the mean.
  • Forgetting that the conditions (Random, 10%, Normal/Large) must hold for the interval to justify anything.

2. Key ideas

Vocabulary

Units, factors, treatments

Experimental units (called subjects if they are people) receive treatments. A factor is an explanatory variable the researcher manipulates; its values are levels. A treatment is a specific condition applied, such as one level or a combination of levels.

Random assignment

Balance the unknown

Assigning treatments by chance tends to create groups that are similar in every variable, known or unknown. Then a large difference in the response can be attributed to the treatments.

Control

Keep other variables the same

Hold other variables constant for all units, and include a control group (placebo, no treatment, or the current standard) for comparison. Blinding keeps expectations from affecting results.

Replication

Enough units per treatment

Use enough experimental units in each group so that real differences can be told apart from chance variation.

Blocking

Group similar units first

A block is a group of units that are similar in a way expected to affect the response. Randomly assign treatments within each block. Blocking reduces variability from that variable, giving more precise comparisons.

Matched pairs

Blocks of two

Pair very similar units (or use each subject twice, in random order) and randomly assign the two treatments within each pair. Analyze the differences within pairs.

3. Designs at a glance

Each design uses randomization differently.

DesignHow treatments are assignedWhy use it
Completely randomizedAll units are randomly assigned to treatments, e.g., put 40 names on slips, shuffle, the first 20 drawn get the new plan.Simple; works when units are fairly similar
Randomized blockSplit units into blocks by a variable related to the response (fitness), then randomly assign treatments within each block.Removes the block variable's effect; more precise
Matched pairsPair the two most similar units, randomly assign one of each pair to each treatment; or give each subject both treatments in random order.Most control over differences between units
Double-blindNeither the subjects nor the people measuring the response know who got which treatment.Prevents expectations from biasing results
Placebo controlThe control group gets a fake treatment that looks like the real one.Accounts for the placebo effect

4. On the FRQ

How to earn the points

  • Describe random assignment completely: label units, use a random device, assign the first half to one treatment and the rest to the other.
  • For a block design, name the blocking variable, explain why it is related to the response, and say treatments are randomly assigned within each block.
  • Explain the purpose of random assignment in context: "to create roughly equivalent groups, so that differences in push-up gains can be attributed to the workout plan."
  • State the scope: cause-and-effect conclusions need random assignment; generalizing to a population needs random selection.
  • Describe how you will compare: "Compare the mean increase in push-ups for the two groups."

Common mistakes

  • Confusing random assignment (allows cause and effect) with random selection (allows generalizing to a population).
  • Saying blocking "reduces bias." Random assignment handles bias; blocking reduces variability.
  • Letting subjects choose their treatment and still calling the conclusion causal.
  • Generalizing results from volunteers to everyone. Volunteers are not a random sample.
  • Calling the blocking variable a treatment. Researchers do not assign it.

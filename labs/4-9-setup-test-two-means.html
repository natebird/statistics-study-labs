2. Key ideas

Design

Paired vs. two-sample

If each value in one group is naturally linked to one value in the other (same person, twins, the same car), the data are paired: analyze the differences with a one-sample t procedure. Otherwise use a two-sample t procedure.

Parameters

Hypotheses are about populations

Write hypotheses with μ₁ and μ₂, never x̄₁ and x̄₂. Define each one in context: "μ₁ = the true mean height of plants given the new fertilizer."

Null

H₀ says "no difference"

The null hypothesis is almost always H₀: μ₁ − μ₂ = 0 (equivalently μ₁ = μ₂). It is the claim we look for evidence against.

Alternative

Read the question's wording

"Greater," "taller," "more" → >. "Less," "lower," "reduce" → <. "Different," "changed," "any difference" → ≠. Decide this before looking at the data.

Conditions

Random, 10%, Normal/Large

Random samples or random assignment; each sample at most 10% of its population when sampling; each n ≥ 30, or that sample's data show no strong skew or outliers.

Scope

What can we conclude?

Random sampling lets you generalize to the populations. Random assignment lets you conclude cause and effect. A convenience sample allows neither.

4. On the FRQ

How to earn the points

  • Name the test: "two-sample t-test for a difference in population means."
  • State both hypotheses with symbols and define the parameters in context, including which group is 1 and which is 2.
  • State the significance level: "α = 0.05."
  • Check each condition with evidence from the problem, not just its name. For small samples, refer to the graph of each sample.

Common mistakes

  • Writing hypotheses with sample statistics: "H₀: x̄₁ = x̄₂."
  • Choosing the direction of Hₐ after seeing which sample mean is bigger.
  • Using a two-sample test for paired data, or a paired test for independent groups.
  • Checking "n₁ + n₂ ≥ 30." Each sample must be checked on its own.
  • Saying "the population is normal" when you only looked at a sample graph. Say the sample shows no strong skew or outliers.

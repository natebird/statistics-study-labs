2. Key ideas

State

Hypotheses and α

Write H₀ and Hₐ about p, define p in context, and give α.

Plan

Name it and check it

One-sample z-test for p. Check Random, 10% (n ≤ 0.1N), and Large counts with p₀ (np₀ ≥ 10 and n(1 − p₀) ≥ 10).

Do

Test statistic

z = (statistic − parameter) ÷ (SD of statistic) = (p̂ − p₀) ÷ √(p₀(1 − p₀)/n). It counts how many SDs p̂ is from p₀.

Do

p-value

Find the area under the standard normal beyond z in the direction of Hₐ; double it for ≠.

Conclude

Link, decide, context

"Because the p-value of 0.015 is less than α = 0.05, we reject H₀. There is convincing evidence that …"

Calculator

zproptest (Desmos) · 1-PropZTest (TI-84)

In Desmos, zproptest(x, n), then set the null to p₀ and the Left/Both/Right tail; read T₁.score and T₁.p (or .pleft / .pright). On the TI-84, STAT ▸ TESTS ▸ 1-PropZTest. Either gives z and p, but on the FRQ you must still show the formula with numbers and state the conditions.

4. On the FRQ

How to earn the points

  • Every step counts. Missing conditions or context costs points even with correct calculations.
  • Show the test statistic formula with values substituted before giving z.
  • Write the p-value as a probability statement: P(Z ≥ 2.18) = 0.0147 (Desmos 1 - normaldist(0, 1).cdf(2.18), TI-84 normalcdf(2.18, 1E99, 0, 1)). The command alone is not enough.
  • In the conclusion, explicitly compare: "p-value 0.0147 < α = 0.05."
  • Use "convincing evidence" (or "not convincing evidence") and finish with the population parameter in context.

Common mistakes

  • Using p̂ in the standard deviation of a test (that's for intervals).
  • Concluding "H₀ is true" or "accept H₀" when failing to reject.
  • Writing conclusions about the sample instead of the population.
  • Forgetting to double the tail area for a two-sided test.
  • Listing conditions by name without checking them with the actual numbers.

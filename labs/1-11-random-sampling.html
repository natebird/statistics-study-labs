2. Key ideas

SRS

Simple random sample

Every group of n individuals has the same chance to be the sample. Label every individual, then use a random number generator (or names from a hat) to pick n different labels.

Stratified

Similar groups, sample from each

Split the population into strata of similar individuals (like grade level), then take an SRS within each stratum. When the strata differ on the variable, this gives more precise estimates than an SRS of the same size.

Cluster

Pick whole groups

Split the population into clusters, usually by location (like homerooms), randomly choose some clusters, and include everyone in them. It is cheaper and easier. It works best when each cluster is a mini-version of the population.

Systematic

Every kth individual

From an ordered list, pick a random starting point from the first k, then take every kth individual after it. It is easy, but it can go wrong if the list has a repeating pattern.

Strata vs. clusters

Opposite ideas

Strata are alike within and different between; you sample some from every stratum. Clusters are mixed within and similar between; you sample all from some clusters.

Census

Everyone

A census measures every individual. It gives the parameter exactly but is often too slow, costly, or impossible for a large population.

4. On the FRQ

How to earn the points

  • Describe a method so someone else could carry it out: what you label, how many labels, the random device, and "ignore repeats."
  • For stratified sampling, name the strata and explain why they help: "Sleep is likely to differ by grade, so stratifying by grade gives a more precise estimate."
  • For cluster sampling, explain the practical benefit: "It is easier to survey two full homerooms than 20 students scattered across the school."
  • Use "random" only when a chance process actually chooses the individuals.

Common mistakes

  • Mixing up strata and clusters. Stratified: some from every group. Cluster: everyone from some groups.
  • Saying a sample "is random" because the researcher chose "without a pattern." Haphazard is not random.
  • Forgetting to handle repeats when using a random number generator.
  • Thinking stratifying always helps. It helps only when the strata really differ on the variable being measured.

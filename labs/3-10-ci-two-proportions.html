2. Key ideas

Form

Estimate ± margin of error

Every confidence interval is point estimate ± (critical value)(standard error). Here the estimate is p̂₁ − p̂₂ and the critical value is z*.

Standard error

Use the sample proportions

Because p₁ and p₂ are unknown, the standard error plugs in p̂₁ and p̂₂: SE = √( p̂₁(1 − p̂₁)/n₁ + p̂₂(1 − p̂₂)/n₂ ).

Conditions

Random, 10%, large counts

Two independent random samples or a randomized experiment; each sample ≤ 10% of its population (for sampling); and at least 10 successes and 10 failures in each group.

Interpret the interval

Plausible values

"We are 95% confident that the interval from −0.02 to 0.11 captures the true difference p₁ − p₂." Always say which group was subtracted from which, and give context.

Interpret the level

Long-run capture rate

95% confidence means that if we took many pairs of samples and built an interval from each, about 95% of those intervals would capture the true difference. It is not a probability about this one interval.

Width

What makes it narrower

Lower confidence (smaller z*) and larger sample sizes (smaller SE) both shrink the interval. Higher confidence costs precision.

4. On the FRQ

How to earn the points

  • Define the parameter with both groups and the order of subtraction: "p₁ − p₂, the difference between the proportion of all city drivers and all rural drivers who wear seatbelts."
  • Name the procedure exactly: two-sample z-interval for a difference in proportions.
  • Check large counts with the observed successes and failures in both samples, with numbers.
  • Show the formula with values substituted, even if you use 2-PropZInt on a calculator.
  • Interpret in context and with the parameter, not the statistic: the interval captures the true difference.

Common mistakes

  • Saying "there is a 95% probability that the true difference is in this interval." The interval either captures it or not.
  • Interpreting the interval as describing the sample proportions. We already know p̂₁ − p̂₂ exactly.
  • Using the pooled proportion. Pooling is only for tests with H₀: p₁ = p₂.
  • Forgetting which group came first, then misreading a negative interval.
  • Checking the 10% condition for an experiment with volunteers. Random assignment replaces random sampling there.

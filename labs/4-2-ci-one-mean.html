    2. Key ideas

    Why t?

    s replaces σ

    We almost never know σ, so we estimate it with s. That adds extra variability, so we use a t distribution: symmetric and centered at 0 like z, but with heavier tails. The t* critical values are bigger than z*.

    Degrees of freedom

    df = n − 1

    Each sample size gives a different t curve. As df grows, the t curve gets closer to the standard normal curve, and t* gets closer to z*.

    Paired data

    One list of differences

    When each subject is measured twice (or subjects are matched in pairs), subtract within each pair. Then treat the differences as one sample: x̄d, sd, and n = number of pairs.

    Conditions

    Random, 10%, Normal/Large

    Random: random sample or random assignment. 10%: n ≤ 10% of the population when sampling without replacement. Normal/Large: population normal, or n ≥ 30, or a graph of the data shows no strong skew or outliers.

    Interpretation

    Confident about the parameter

    "We are 95% confident that the interval from 6.2 to 7.4 hours captures the true mean sleep time of all students at this school." Name the parameter and the context.

    Confidence level

    A long-run capture rate

    95% confidence means that if we took many random samples and built an interval from each, about 95% of those intervals would capture μ. It is not the probability that this one interval contains μ.

    4. On the FRQ

    How to earn the points

    • Name the procedure and parameter: "One-sample t interval for μ = the true mean sleep time of all students at the school."
    • Check all three conditions with evidence, not just the word: "n = 12 < 30, but a dotplot of the data shows no strong skew or outliers."
    • Do: write the formula with numbers: 6.71 ± 2.201 (1.010/√12) = (6.07, 7.35), df = 11.
    • Conclude in context: "We are 95% confident that the interval from 6.07 to 7.35 hours captures the true mean…"
    • For paired data, say what the difference means (after − before) and that n is the number of pairs.

    Common mistakes

    • Using z* instead of t* when σ is unknown.
    • Treating paired data as two independent samples. If the same subjects are measured twice, use the differences.
    • Saying "95% of the data fall in the interval." The interval is about the mean, not individual values.
    • Saying "there is a 95% probability that μ is in this interval." The 95% describes the method, not one interval.
    • Skipping the Normal/Large check for a small sample, or checking it with the population when you only have the sample.

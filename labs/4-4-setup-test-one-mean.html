      2. Key ideas

      Parameter

      Hypotheses are about μ, never x̄

      Hypotheses describe the population, so they use the parameter μ (or μd). Define it in context: "μ = the true mean delivery time of all pizzas from this chain."

      Null

      H₀ has the equals sign

      The null hypothesis is the claim of "no effect" or "no change": μ = μ₀, or for paired data μd = 0. We assume it is true while we check how surprising the data are.

      Alternative

      Hₐ is what you suspect

      Read the question for direction words: "more than," "less than," "different from." Choose Hₐ before looking at the data. Use ≠ when either direction matters.

      Paired or not?

      Same subjects twice → paired

      If each subject gives two measurements (before/after, left/right, two conditions), or subjects are matched in pairs, test μd using the differences. Define the order of subtraction.

      Conditions

      Random, 10%, Normal/Large

      Random sample or random assignment; n ≤ 10% of the population when sampling without replacement; population normal, n ≥ 30, or a graph of the sample (or differences) with no strong skew or outliers.

      Significance level

      α is set in advance

      α is the cutoff for "convincing." Common choices are 0.05 and 0.01. A smaller α demands stronger evidence before rejecting H₀.

      4. On the FRQ

      How to earn the points

      • Write both hypotheses with the parameter symbol and define it in words: "where μ = the true mean delivery time for all pizzas from this chain."
      • For paired data, define the difference: "μd = the true mean difference in score (music − silence) for volunteers like these."
      • Name the test: "one-sample t test for a mean" or "paired t test for a mean difference."
      • Check each condition with a reason tied to the problem, such as "25 < 10% of all deliveries" or "the dotplot of differences shows no outliers."
      • State α if it is given; otherwise use α = 0.05 and say so.

      Common mistakes

      • Writing hypotheses about x̄ ("H₀: x̄ = 30"). We already know x̄; the question is about μ.
      • Putting the suspected claim in H₀, or using ≥ or ≤ in H₀ (on the AP exam, H₀ uses =).
      • Choosing the direction of Hₐ after seeing the sample result.
      • Using a two-sample test when the same subjects were measured twice.
      • Saying "the population is normal" without evidence. For small samples, look at a graph of the data.

1. Test a claim with an interval

A confidence interval lists the plausible values of μ₁ − μ₂. To judge a claim, check where the claimed value sits: inside the interval means it is plausible; outside means the data give convincing evidence against it.

2. Key ideas

Plausible values

The interval is a list of believable answers

Every value in the interval is a plausible value of μ₁ − μ₂. Values outside the interval are not plausible at that confidence level.

Zero

Is there a difference?

If 0 is outside the interval, the data give convincing evidence that the population means differ. If 0 is inside, "no difference" is plausible, so we do not have convincing evidence of a difference.

Not proof

Plausible is not proven

When 0 is in the interval, never say the means are equal. Many other values, some positive and some negative, are plausible too.

One-sided claims

Look at the whole interval

For "group 1's mean is more than d higher," you need every plausible value above d, so the lower endpoint must exceed d. If d is inside the interval, the claim is plausible but not convincingly supported.

Width

Three levers

The interval gets narrower with a lower confidence level, larger samples, or less variability in the data. Quadrupling both sample sizes roughly halves the margin of error.

Tests

Intervals and two-sided tests agree

A C% interval and a two-sided test at α = 1 − C give the same answer about d: d is rejected by the test exactly when it is outside the interval.

4. On the FRQ

How to earn the points

  • Refer to the interval directly: "Because all values in the interval (2.1, 7.4) are greater than 0…"
  • Connect to the claim in context: "…the data give convincing evidence that students who use the app have a higher mean exam score."
  • When 0 is inside, say "0 is a plausible value for the difference," and stop there. Do not accept "no difference."
  • If asked about precision, name the lever: "Increase both sample sizes to decrease the margin of error."

Common mistakes

  • "The interval contains 0, so the means are equal." Plausible is not proven.
  • Judging by the point estimate alone ("4.7 is bigger than 0") without the interval.
  • Reading the sign backward. The order of subtraction decides which group a positive interval favors.
  • Saying a wider interval is "more accurate." It is more confident but less precise.
  • Thinking a larger sample raises the confidence level. It narrows the interval at the same level.
